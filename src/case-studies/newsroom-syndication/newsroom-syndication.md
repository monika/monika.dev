## The Problem

AdRoll's newsroom had been excluded from sitewide search since launch — real content, not discoverable. Search Console data confirmed the demand: queries like *"adroll news"* generated 1,500+ combined impressions at sub-1% click-through, several already ranking position 1 with nothing worth clicking.

## The Approach

Syndicated the existing newsroom content into the search index — no new content needed, just connecting demand to what already existed. Built the publishing framework so the brand manager could update it independently, extending a self-service authorship pattern I'd already built for the blog.

## Outcome

- Closed a real, measurable demand gap using existing content — no new production required
- Self-service: the brand team publishes independently, with no developer needed per update
- Built simple and documented, so it holds up for whoever maintains it next

## Why It Matters

I build to last by keeping things simple — legible to the next person, technical or not. The highest-leverage move often isn't creating something new; it's noticing good work isn't being used, and fixing the connection.

## Responsibilities

- Search-demand analysis in Google Search Console
- Syndication of newsroom content into the search index
- Self-service publishing framework and its documentation
